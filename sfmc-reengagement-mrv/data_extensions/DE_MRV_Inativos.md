# Data Extension: DE_MRV_Inativos

**Função:** Armazenar os contatos inativos, que serão a audiência-alvo para o reengajamento. Esta é a DE de saída da automação e de entrada no Journey Builder.

**Campos:**

| Nome do Campo         | Tipo      | Propriedades      |
|-----------------------|-----------|-------------------|
| Email                 | Text      | Primary Key       |
| Nome                  | Text      | Nullable          |
| Telefone              | Phone     | Nullable          |
| Data_Ultima_Interacao | Date      | Nullable          |
